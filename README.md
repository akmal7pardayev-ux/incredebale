# incredebale

Two single-file website design studies. Open either `index.html` in a browser, no build step needed.

## Shizuka Dental — `dental/`

A calm, Japanese-minimal site for a same-day toothache clinic, designed around what a patient in pain needs within seconds:

- A live open / closed status and the next free appointment time
- One-tap call and booking, with a pinned action bar on phones
- An interactive pain check that tells you how urgent it is and what helps right now
- Honest prices, a four-step first visit, hours, map and FAQ

Polished with the [unslop](https://github.com/heydamir/unslop) skill by Damir Sokolovsky ([@heydamir](https://x.com/heydamir)).

## NOCTIS — `noctis/`

A WebGL scroll experience for a fictional luxury speaker brand, built with Three.js: a living iridescent orb, a fly-through product gallery, scroll-reactive glitch post-processing, kinetic type and a generated ambient soundtrack.

## Note

Both brands are fictional. The clinic, doctors, prices, reviews, products and phone numbers are placeholders made for these design concepts.
